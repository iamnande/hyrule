# decisions

one file per decision worth not silently re-litigating - the kind an agent
(or future you) might otherwise "helpfully" revert because the alternative
looks reasonable in isolation. not every choice needs one; if
conventions.md's rationale is enough, stop there.

format: `NNNN-slug.md`, numbered in order made. each file is short -
context, the decision, why the alternative(s) lost. no status field, no
template ceremony; if a decision gets reversed, add a new numbered file that
supersedes it rather than editing history.
